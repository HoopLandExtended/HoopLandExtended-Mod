# Security and Privacy

Please do not post passwords, tokens, save files, or other sensitive account data
in public issues.

HLE diagnostic reports intentionally exclude native saves and HLE career state,
but logs may still contain local machine paths or gameplay details. Review a
report before attaching it publicly.

If you believe you found a security-sensitive problem that should not be posted
publicly, contact the project through the email listed on the Hoop Land Extended
GitHub account rather than opening a public issue.
