# Security and Privacy

Do not post passwords, tokens, native save files, or other sensitive account data in public issues.

HLE reports exclude native career-save files, but include diagnostic logs and HLE sidecar state needed to inspect training, mastery, Form, mentorship, identity, and transaction recovery. They can contain local user paths, player identities, career history, and other gameplay details. Review and redact a report before attaching it publicly. A report is not a complete save backup. HLE does not automatically upload reports.

For a security-sensitive problem, contact the project through the email listed on the Hoop Land Extended GitHub account rather than opening a public issue.
