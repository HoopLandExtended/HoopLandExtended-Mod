# Hoop Land Extended - Quick Start

**Windows x64 | Steam | Illustrated with v0.4.0-alpha.1**

1. Open [HLE Releases](https://github.com/HoopLandExtended/HoopLandExtended-Mod/releases) from the [official repository](https://github.com/HoopLandExtended/HoopLandExtended-Mod).
2. Under **Assets**, download the versioned HLE ZIP, not GitHub's **Source code (zip)** archive.
3. Optionally **Unblock** the ZIP in Windows Properties if shown, then **Extract All**. Keep HLE **outside** the Steam game folder.
4. Open **HLE.exe** from the extracted release folder.
5. In the first-run setup, choose the **original Steam Hoop Land folder** (Steam > Library > Hoop Land > Manage > Browse local files), select modules, and click **Set up HLE**.
6. Once setup completes, select **Play HLE**. The first run may take longer than usual.

**Back up native saves and matching HLE state before updates.** Separate HLE copies can share native save slots.

**Updating?** Close game and launcher; back up; copy new release contents into existing HLE package, **preserving `Game` and `installed.json`**, then open HLE.exe and use **Update HLE**.

**Need support?** Use HLE.exe > Tools > Collect Report and open a [GitHub issue](https://github.com/HoopLandExtended/HoopLandExtended-Mod/issues).
