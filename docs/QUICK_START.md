# HLE 0.5.0 Alpha 1 — Quick Start

1. Download **HLE-0.5.0-alpha.1-Windows.zip** from [Releases](https://github.com/HoopLandExtended/HoopLandExtended-Mod/releases/tag/v0.5.0-alpha.1). Do not use GitHub's autogenerated Source code ZIP.
2. Extract the entire archive. Open the enclosing **HLE** folder and run **HLE.exe** (Windows may show it as HLE).
3. Select your supported Steam Hoop Land folder, choose modules, and finish setup. Keep HLE outside Steam. Internet is needed for first setup.
4. Select **Play HLE**. Use HLE.exe for settings, help, tools, updates, and future launches.

**Updating:** Close the game and launcher. Copy the contents **inside** the new HLE folder into your existing HLE root, replacing supplied files while preserving Game/HLE_Data and state. Open HLE.exe; it reorganizes the old layout automatically. Use Update HLE if offered. Do not nest a new HLE folder inside the old one.

Back up native saves and matching HLE state. Separate game copies can share native save slots. Help opens the [quick PDF](HLE_Quick_Start.pdf) and [full guide](HLE_Installation_Guide.pdf). See [installation](INSTALL.md), [release notes](releases/v0.5.0-alpha.1.md), and [verification](VERIFICATION.md).
