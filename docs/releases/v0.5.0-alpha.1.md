# Hoop Land Extended 0.5.0 Alpha 1

This public alpha brings the integrated Player Evolution update and the reorganized HLE launcher to the v0.4.0 foundation. It is a complete Windows package for fresh setup or an in-place update.

## Player Evolution

- **CPU Training:** Up to three team opportunities on eligible recovered days, using native category XP and the normal five-condition cost. Base XP is 5; coaching and qualified active mentorship raise it through native 7/10 tiers. The default minimum gap between a CPU player's sessions is two days. Native levels, AP, potential, and upgrades remain authoritative. The career player's practice slot is reserved.
- **Veteran Mentorship:** Persistent assignments, up to two mentees per qualified veteran and one active mentee per veteran/day. Relevant ordinary native or HLE skills can receive one session credit, subject to caps and native prerequisites. Legendary Abilities are excluded.
- **Instant Practice:** Independently selectable +5 category XP, or +7 after that category records one genuine +10 manual result. Native time/condition costs and daily duplicate prevention apply. Native manual practice is unchanged.
- **Persistent Form:** Separate Shooting, Finishing, Creating, and Defense episodes from qualified personal evidence. Rookies build evidence rather than being excluded for their first season. Modest category effects use scoped native consumers, with a maximum eight consecutive team games. Ambiguous evidence is withheld locally.
- **Draft Regression:** Class-based NBA-entry treatment of the twelve current nonphysical attributes: freshman −4, sophomore −3, junior −2, senior/later −1. Potential, ceilings, physicals, valid custom values, and skill continuity are preserved. Uncertain transitions keep the safe native result rather than guessing or applying another blanket deduction.

Ordinary HLE skill requirements now scale with native season/game-length rules and individual event rarity. Legendary requirements are unchanged. Athleticism, Expanded Skills, Legendary Abilities, Finance, financial-profile persistence, fans, social features, front-office controls, CPU trades, and draft-skill recovery remain integrated.

## Launcher and persistence

Extracting the ZIP creates one **HLE/** folder. Its root contains HLE.exe, Instructions.pdf, README.md, Documentation, and HLE_Data. Open HLE.exe. Help opens both guides; Tools exposes reports, logs, backups, imports, repair, and optional Form validation. Automatic legacy migration preserves game/state/settings and archives recognized old package files with a resumable journal.

The expanded report collector retains complete season archives for up to three seasons per world/branch/league and includes compatible HLE state without native save files. The unhelpful Development Draft page is removed; the regression system remains available as an independent module.

Windows setup fixes include the short pinned SDK cache, safe five-plugin installation, explicit Finance profile-pack assets, and removal of stale verifier caches. Archives are built in memory, checked in full, and atomically published to prevent incomplete ZIPs from being delivered.

## Installation and updating

Download **HLE-0.5.0-alpha.1-Windows.zip**, not GitHub's automatic Source code archive. For a new installation, extract all files, open HLE/HLE.exe, select your supported Steam game, and complete setup. For an update, close the game/launcher and copy the contents inside HLE/ into the existing HLE folder, replacing supplied package files while preserving existing game and state. Open HLE.exe and use Update HLE if offered. Do not nest a new HLE folder inside the old one.

Keep native career and matching HLE-state backups. Separate game copies may share native save slots. For a separate new installation, use Tools → Import previous HLE state after setup, selecting the prior Game or HLE_Data/Game folder.

## Validation and remaining limits

Windows reports confirm setup/launch, CPU training, native and HLE mentorship credits, practice mastery, and saved-state continuation. The latest session records 261 completed training sessions, 2,456 persisted committed practice events, zero uncertain practice events, a ready financial ledger, a complete season archive, and no HLE runtime errors. Prior native reports exercised simulated Hot/Cold Shooting, Hot Creating, and Hot Defense effects.

All five shipped game DLLs and 444 production source files match the accepted dev.13 baseline. The public promotion changes labels, documentation, sanitized evidence, and packaging only. Managed/isolated fixture results and Windows observations are documented separately in Verification-Report.md.

Long-term talent inflation/fatigue, full played-versus-simulated effect parity, and ordinary skill event-frequency calibration remain alpha work. Defense requires reliable contested-shot attribution. Ambiguous encounters, dunks, free throws, and unclassified special finishes do not receive unsupported Form effects. Background training is skipped where no reliable native recovery boundary is known. Selective playing-time morale protection and Form-aware lineups remain withheld. No new traits or currencies are added.

Form validation is **Off** by default and is optional troubleshooting. Reports may include HLE state, local paths, and gameplay information; review before attaching them to public issues. Complete source, pinned companion provenance, build instructions, and automated evidence are included under HLE_Data/Developer.

Recommended for broader **alpha testing**, not a stable release. Hoop Land is required and is not included.
