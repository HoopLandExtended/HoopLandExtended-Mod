# Windows alpha acceptance checklist

Use native-save and matching HLE-state backups. Keep optional Form validation Off during ordinary play. One normal session can cover these checks; no multi-hour Form matrix is required.

1. Extract the whole ZIP and open HLE/HLE.exe. For an existing installation, copy the contents inside HLE into its current root, preserving game/state, then use Update HLE if offered. Confirm setup completes and module choices persist.
2. Confirm Help opens both guides and Tools opens game/log/report folders. Load an existing career through Play HLE.
3. Open the practice facility and HLE Development. Confirm the entry does not overlap native confirmation, plans/mentors are readable, and the entry returns after leaving/reopening. Assign a plan if desired.
4. Use manual or Instant Practice once. Confirm the normal condition/time cost and no duplicate same-day reward. Genuine +10 manual results should unlock +7 Instant Practice for that category on a later day.
5. Play or simulate a few ordinary days. Review CPU training and mentorship status; eligible CPU sessions use 5/7/10 XP and five condition. Form appears only when sufficient qualified evidence warrants it; no streak in a short session is normal.
6. Save, close, relaunch, and confirm plans, credits, mastery, and earned HLE progression persist. Check existing Skills, Athleticism, Legendary Abilities, Finance, fans/social, and front-office screens during ordinary play.
7. Collect one report after closing the game if a problem appears. Review it for local paths and HLE career details before posting to GitHub Issues. Reports exclude native saves and are not complete backups.

Trade offers, Form episodes, and draft transitions need not occur in every session. Do not fabricate actions or play extra long games merely to force them. Wider alpha feedback will build long-term and less frequent transition coverage. See Verification-Report.md for evidence already established and remaining limits.
